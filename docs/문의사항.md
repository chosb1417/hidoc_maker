## 1. 부가세 끝자리 처리

부가세(10%)를 계산하다 보면 1원 미만이 생깁니다. 지금 프로그램은 135원 → 14원, 125원 → 12원으로 기준이 섞여 있어 하나로 정하려고 합니다.

| 예시 (단가, 부가세 별도) | 반올림 | 버림 |
|---|---|---|
| 135원 → 부가세 13.5원 | 14원 | 13원 |
| 125원 → 부가세 12.5원 | 13원 | 12원 |

## 2. 부가세를 품목별로 계산할지, 합계로 계산할지

예) 135원짜리 품목이 3개 줄로 있을 때 (부가세 별도)

| 방식 | 부가세 |
|---|---|
| 품목마다 계산해서 더하기 (반올림 기준) | 14 + 14 + 14 = **42원** |
| 공급가액 합계 405원에 10% (반올림 기준) | **41원** |

- [ ] 품목별로 계산해서 더함
- [ ] 합계 금액으로 한 번에 계산
- [ ] 견적서 방식을 따름
