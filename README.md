# hidoc maker

입력창에 구매 내용을 적으면 한글(`.hwp`) 품의서를 만들고, 붙임 서류를 기업별·날짜별 폴더에 정리해 주는 프로그램입니다.

## 실행

- `실행.bat`을 더블클릭합니다. 필요한 것이 없으면 먼저 설치한 뒤 입력창이 뜹니다.
- 또는 이 폴더에서 `python -m hidoc`을 실행합니다.

### 필요한 것

| 항목 | 설치 |
|---|---|
| Python 3.14 이상 (Tk 9 포함) | `실행.bat`이 PATH의 `python` → `py -3` → 기본 설치 위치 순서로 Tk 9 이상인 Python을 찾아 씀(`hidoc/check_python.py`). 없으면 winget으로 Python 3.14 설치. Tk 9가 없으면 입력칸 예시 글자를 직접 그리는 방식으로 대신함 |
| 파이썬 패키지 (`pywin32`, 견적서 읽기용 `pdfplumber`·`winrt`·`anthropic` 등) | 없으면 `실행.bat`이 `requirements.txt`로 자동 설치 |
| 한컴오피스 한글 (2024에서 확인) | 직접 설치. 없으면 안내만 하고 실행되며, 하이웍스 복사만 쓸 수 있음 |
| Windows 한국어 OCR | 한국어 Windows에는 기본으로 있음. 스캔본 견적서를 로컬 방식으로 읽을 때 필요 |
| Claude Code + Claude 구독 로그인 | Claude Code 방식으로 견적서를 읽을 때만 필요. 없으면 입력창이 공식 설치(`irm https://claude.ai/install.ps1 \| iex`, 관리자 권한 불필요)와 로그인을 차례로 안내함. PATH의 `claude`, `%USERPROFILE%\.local\bin\claude.exe`, VS Code 확장 순서로 찾음. Pro·Max 이상 유료 구독 필요 |
| Claude API 키 | 화면에서 숨긴 Claude API 방식을 `settings.json`으로 켰을 때만 필요. `anthropic_api_key`에 직접 적음 (키 없이 불러오면 그때 물어봄) |

## 첫 화면과 설정

실행하면 첫 화면에 탭 두 개가 있습니다.

- **문서 만들기**: 만들 문서를 고릅니다. 지금은 `구매 품의서` 하나입니다. 고르면 같은 창이 작성 화면으로 바뀌고, 위쪽 `← 처음으로`로 돌아옵니다. 작성 화면은 계속 남아 있어서 처음으로 갔다 와도 입력한 내용이 유지됩니다.
- **설정**: 바꾸면 바로 `settings.json`에 저장되고, 작성 화면을 열 때 반영됩니다. 탭을 열 때마다 환경 점검을 다시 합니다.

### 설정 항목 (`settings.json`)

값이 없거나 비어 있으면 기본값을 씁니다(`hidoc/settings.py`의 `DEFAULTS`, `get_setting`).

| 키 | 설정 탭 | 내용 | 기본값 |
|---|---|---|---|
| `save_dir` | 파일 경로 (출력) | 저장 경로. 실제로는 그 안의 `hidoc_output` 폴더에 저장(`settings.output_dir`, 저장 경로가 이미 `hidoc_output`이면 그대로). 작성 화면 아래 저장 경로 줄과 같은 값 | 프로그램 폴더 |
| `quote_dir` | 파일 경로 (입력) | 견적서 불러오기 창이 처음 열릴 폴더 | Windows 다운로드 폴더 |
| `attach_dir` | 파일 경로 (입력) | 붙임 파일 선택 창이 처음 열릴 폴더 | Windows 다운로드 폴더 |
| `read_mode` | 견적서 읽기·Claude | 기본 읽기 방식 `local` / `claude_code` / `claude`. 작성 화면에서 바꿔도 저장됨 | `local` |
| `anthropic_api_key` | 숨김 | Claude API 키 (암호화하지 않고 저장, git 제외). Claude API 방식은 읽기 방식 목록에서도 숨김 — `read_mode`를 `claude`로 적어야 씀 | 없음 |
| `company_names` | 숨김 | 우리 회사 이름. 견적서에서 견적처 후보로 보지 않고, Claude에게도 알려 줌 | `["지아이랩", "gailab"]` |
| `payment_example` | 숨김 | 작성 화면 지급방식 칸이 비어 있을 때 보이는 예시 글자 (값은 아님) | `선금 50% , 잔금 50%` |
| `attach_types` | 숨김 | 붙임 종류 드롭다운 목록 | 사업자등록증, 통장사본, 견적서, 거래명세서, 전자세금계산서, 계약서, 발주서, 검수확인서 |
| `company_docs` | 숨김 | 기업 폴더 바로 아래에 날짜 없이 저장하는 기업 공통 서류 | 사업자등록증, 통장사본 |

숨김 값은 설정 탭에 보이지 않습니다. 바꾸려면 `settings.json`에 같은 키로 직접 적습니다(예: `"payment_example": "후불"`).

- 다운로드 폴더는 Windows에 등록된 실제 위치를 읽습니다(사용자가 `D:` 등으로 옮긴 경우 포함).
- 환경 점검 항목: Python·Tk(9 이상 권장), 한컴오피스 한글, Windows 한국어 OCR, 필요한 패키지, Claude Code(설치·로그인·요금제). Claude Code 줄 옆 `설치`·`로그인` 버튼은 견적서 읽기 때와 같은 공식 설치·로그인 창을 띄우고, 창이 닫히면 다시 점검합니다.

### 새 문서 추가하기

1. `hidoc/` 안에 작성 화면 클래스를 만듭니다. `ttk.Frame`을 상속하고, 생성자는 `master` 하나, 설정을 다시 읽는 `refresh_from_settings()` 메서드를 둡니다(`purchase_form.py` 참고).
2. `hidoc/documents.py`의 `DOCUMENTS`에 `DocumentType(key, 이름, 설명, 화면 클래스)`를 한 줄 추가하면 첫 화면에 버튼이 생깁니다.

## 사용 방법 (구매 품의서)

첫 화면 `문서 만들기` 탭에서 `구매 품의서`를 누른 뒤:

1. **기본 정보**를 입력합니다.
   - 구매대상: 본문 문장과 제목에 쓰입니다.
   - 제목: 비워두면 "구매대상 + 구매의 건"으로 자동 작성됩니다.
   - 견적처: 기업명입니다. 꼭 입력해야 하고, 저장 폴더와 파일 이름에 쓰입니다. 칸 오른쪽 ▼를 누르면 저장 경로\hidoc_output 안에 이미 있는 기업 폴더가 최근 순으로 나와서 고를 수 있고, 목록에 없으면 새로 입력합니다(저장하면 폴더가 생겨 다음부터 목록에 나옴). 입력하는 동안에도 입력한 글자가 들어간 기존 기업이 칸 아래에 뜹니다(공백·영문 대소문자 무시, 한글은 조합 중인 마지막 글자까지 포함). 마우스로 누르거나 `↓`·`↑`로 고르고 `Enter`, 닫으려면 `Esc`. 이름이 기존 폴더와 완전히 같으면 그 폴더를 그대로 씁니다. 폴더 이름은 파일 이름에 못 쓰는 글자·공백이 `_`로 바뀐 이름입니다.
   - 지급방식: 비어 있고 칸 안에 예시(`예) 선금 50% , 잔금 50%`)가 보입니다. **입력하지 않으면 품의서에서 4번 지급방식 항목이 빠집니다.**
   - 구매처: 쿠팡 같은 온라인 구매일 때 주소(URL, 예: 장바구니 주소)를 넣습니다. 넣으면 품의서에 `4. 구매처 : 주소`가 들어가고, 지급방식도 있으면 `5. 구매처`가 됩니다. 비우면 항목이 빠집니다. 온라인 구매는 보통 세액을 `없음`으로 두고(판매가를 그대로 공급가액으로), 배송비는 품목 한 줄로 넣습니다.
2. **견적내역**에 품목, 수량, 단가, 세액 구분, 비고를 넣고 `추가`를 누릅니다.
   - 목록에서 품목을 고르면 입력칸에 불러와져서 `수정`이나 `삭제`를 할 수 있습니다.
3. **지급방식 상세**를 한 줄에 하나씩 적습니다. 앞에 `- `가 자동으로 붙습니다. 지급방식 칸은 비우고 상세만 적으면 `4. 지급방식` 제목 아래 상세만 들어갑니다.
4. **붙임**을 정리합니다.
   - 종류는 드롭다운에서 고르고, 목록에 없는 종류는 직접 입력해도 됩니다.
   - 이름을 비우면 기업명이 들어갑니다.
   - 목록에서 항목을 고르고 `파일…`을 누르거나 항목을 더블클릭하면, 실제 파일이 그 항목에 바로 연결됩니다.
   - `비우기`를 누르면 붙임 목록이 전부 지워집니다.
5. **저장 경로**를 정하고 `한글 생성`을 누릅니다. 한 번 만드는 데 7초쯤 걸립니다.

### 견적서 불러오기

기본 정보의 `견적서 불러오기…`를 누르고 견적서 PDF나 이미지를 고르면, 읽는 동안 버튼 아래에 진행 막대와 "견적서 읽는 중…"이 보이고, 다 읽으면 묻지 않고 바로 견적처·구매대상(비어 있을 때)·견적내역을 채우고 고른 파일을 붙임의 견적서에 연결합니다. **지금 입력된 견적내역은 지워지고 새로 채워집니다** — 견적내역에 품목이 있으면 파일을 고르기 전에 팝업으로 알리고(`확인`/`취소`), 비어 있으면 묻지 않습니다. 불러온 결과와 확인할 점(OCR로 읽음, 합계가 다름 등)은 버튼 아래 줄에 주황 글씨로 나옵니다. 품목을 하나도 찾지 못하면 지금 견적내역은 그대로 두고 안내만 합니다.

| 읽기 방식 | 방법 | 비용·조건 |
|---|---|---|
| 로컬 (무료, 기본값) | 글자가 들어 있는 PDF는 글자를 그대로 읽고, 스캔본·이미지는 Windows 내장 OCR로 읽은 뒤 "수량 × 단가 = 금액"이 맞는 줄을 품목으로 찾음 | 무료, 인터넷 불필요, 외부 전송 없음. 양식이 특이하거나 스캔이 흐리면 틀리거나 빠질 수 있음 |
| Claude Code (구독) | 이 PC에 로그인된 Claude Code(`claude -p`)가 문서를 읽음. 파일 읽기 도구만 허용. 구매대상 이름도 제안함. 10초 안팎 | 각자 자기 Claude 구독(Pro/Max)으로 로그인해야 함. 구독 사용 한도에서 차감. API 키로 로그인돼 있으면 요금이 나가지 않도록 막음. 견적서 내용이 Anthropic 서버로 전송됨 |
| Claude API (화면에서 숨김) | Claude(`claude-opus-5-5`)가 문서를 직접 읽음. 구매대상 이름도 제안함. `settings.json`에 `"read_mode": "claude"`와 `anthropic_api_key`를 적어야 씀 | API 키와 인터넷 필요. 견적서 1장에 100원 안팎(어림값). 견적서 내용이 Anthropic 서버로 전송됨 |

- 읽기 방식은 마지막에 고른 것을 기억합니다(설정 탭의 기본 읽기 방식과 같은 값). 견적서·붙임 파일 선택 창은 설정 탭의 입력 폴더에서 열립니다.
- Claude Code 방식에서 Claude Code가 설치되어 있지 않으면 "지금 설치할까요?"라고 묻습니다. `예`를 누르면 파란 PowerShell 창에서 Anthropic 공식 설치가 진행되고(1~2분, 진행 표시 없음), 끝나고 Enter를 누르면 로그인 단계로 넘어갑니다.
- Claude Code 방식에서 로그인이 안 되어 있으면 "지금 로그인 창을 열까요?"라고 묻습니다. `예`를 누르면 검은 창과 브라우저가 열리고, 브라우저에서 Claude 계정으로 로그인한 뒤 검은 창에서 아무 키나 누르면 견적서를 자동으로 다시 읽습니다.
- 회사는 Claude Team 요금제(조직 `Gailab Co`)를 씁니다. Claude Code 방식은 각자 자기 Team 계정으로 로그인해서 쓰세요. 한 사람의 로그인을 다른 PC에 복사해 쓰지 마세요. Team 계정이 아닌 사람은 로컬이나 Claude API 방식을 쓰면 됩니다.
- 부가세는 세액 칸이 있으면 `별도`로, "공급가액 + 세액 = 수량 × 단가"이면 `포함`으로 봅니다. 둘 다 아니면 문서의 "부가세 포함/별도" 문구를 따르고, 문구도 없으면 `별도`로 넣은 뒤 알려 줍니다.
- 견적서의 합계와 읽은 품목의 합계가 다르면 알려 줍니다. OCR로 읽은 경우는 숫자를 꼭 확인하세요.

### 온라인 구매 (쿠팡 등)

쿠팡처럼 견적서 대신 쇼핑몰에서 사는 건은 따로 모드가 없고, 같은 화면에서 아래처럼 입력합니다. 실제 쿠팡 품의서 예시(음향증폭기 모듈 3 Set, 247,350원)를 기준으로 맞췄습니다.

| 칸 | 입력 | 예시 |
|---|---|---|
| 견적처 | 쇼핑몰 이름 | `coupang` |
| 제목 | 비워 두면 자동. 쇼핑몰 표기가 필요하면 직접 씀 (자동으로 붙이지 않음) | `G.Eye-Parking H100 음향증폭기 모듈 (3 Set) 구매의 건 (coupang)` |
| 지급방식 | 비워 둠 (4번 지급방식 항목이 빠짐) | |
| 구매처 | 장바구니·상품 주소(URL) | `https://cart.coupang.com/cartView.pang?traceId=…` |
| 견적내역 세액 | `없음` (판매가를 그대로 공급가액으로, 세액 0) | AMP(ZK-TB21) 6개 × 17,010 |
| 배송비 | 품목 한 줄, 수량 1, 세액 `없음` | 배송비 1 × 3,000 |
| 붙임 | 상품 화면 등을 저장한 파일을 연결, 이름은 직접 | `견적서_AMP 1부.` |

이렇게 넣으면 품의서는 다음과 같이 나옵니다.

```text
1. 견 적 처 : coupang
2. 견적금액 : 금247,350원(금이십사만칠천삼백오십원)
3. 견적내역      (표: 품목 3줄, 세액 0)

4. 구매처 : https://cart.coupang.com/cartView.pang?traceId=mvaqprzc

붙    임 :  견적서_AMP 1부.
            견적서_서지보호기 1부. 끝.
```

- 구매처는 지급방식 다음 번호입니다. 지급방식(또는 상세)도 쓰면 `4. 지급방식`, `5. 구매처` 순서가 됩니다.
- 구매처 칸을 비우면 구매처 항목이 빠집니다. `새로 작성`을 누르면 구매처 칸도 비워집니다.
- 견적서 불러오기는 쇼핑몰 화면 캡처를 읽도록 맞춘 것이 아닙니다. 로컬 방식은 잘 못 읽을 수 있고, Claude Code 방식으로 쇼핑몰 캡처를 읽는 것은 아직 시험하지 않았습니다.
- 원본 예시의 총계 줄 단가 칸(단가 합)과 NO 번호(1, 2, 2)는 따라 하지 않았습니다. 이 프로그램은 번호를 순서대로 매기고, 총계 줄은 지금 방식 그대로입니다.

### 하이웍스에 붙여넣기

한글 문서에서 복사해 하이웍스에 붙여넣으면 가운데 정렬이 풀립니다. 대신 `하이웍스용 복사`를 누르고 하이웍스 작성 화면에 `Ctrl+V` 하세요. 정렬, 표 테두리, 글꼴을 HTML에 직접 지정해서 복사하므로 모양이 유지됩니다. 복사할 때 같은 내용을 프로그램 폴더의 `hidoc_output/preview.html`에도 저장합니다(미리보기용, 덮어씀, 저장 경로 설정과 상관없음).

`새로 작성`을 누르면 입력 내용이 지워지고, 붙임 목록은 기본 다섯 개로 돌아갑니다.

## 개발할 때 실시간으로 보기

- **하이웍스용 HTML**: VS Code에서 `hidoc_output/preview.html`을 열고 오른쪽 아래 `Go Live`(Live Server)를 누릅니다. 브라우저에 `http://127.0.0.1:5500/hidoc_output/preview.html`이 뜨고, 입력창에서 `하이웍스용 복사`를 누를 때마다 자동으로 새로고침됩니다. 파일이 없으면 먼저 한 번 복사하세요.
- **입력창**: `python dev_run.py`로 실행하면, `hidoc` 폴더의 `.py` 파일을 저장할 때마다 입력창이 꺼졌다 다시 켜집니다. 끝낼 때는 터미널에서 `Ctrl+C`. 다시 켜지면 입력한 내용은 지워집니다. 추가 설치는 필요 없습니다.

## 세액 구분 (품목별)

단가 1,100,000원, 수량 1개일 때:

| 구분 | 뜻 | 공급가액 | 세액 | 합계 |
|---|---|---|---|---|
| 별도 (기본값) | 단가 + 10% | 1,100,000 | 110,000 | 1,210,000 |
| 포함 | 단가에 부가세가 들어 있음 (쿠팡 등 소비자가) | 1,000,000 | 100,000 | 1,100,000 |
| 없음 | 면세 (도서, 농산물, 간이·면세사업자, 해외 결제 등) | 1,100,000 | 0 | 1,100,000 |

"포함"일 때 공급가액은 `금액 ÷ 1.1`을 원 단위로 반올림한 값이고, 세액은 금액에서 공급가액을 뺀 값입니다.

견적내역 아래의 `견적금액에 'VAT포함' 표기`를 체크하면 `2. 견적 금액` 줄 끝에 ` VAT포함`이 붙습니다. 표 계산과는 상관없이 글자만 붙습니다. 세액을 0으로 두고 "VAT포함"만 적으려면, 품목을 "없음"으로 넣고 체크하세요.

## 저장 구조

```
저장경로\                                   ← 설정 탭의 저장 경로 (기본값: 프로그램 폴더)
 └ hidoc_output\                         ← 저장 경로를 어디로 고르든 항상 만듦
    └ 엠에스산업\                               ← 견적처(기업명)
       ├ [사업자등록증]엠에스산업.jpg            ← 기업 공통 서류 (날짜 없음)
       ├ [통장사본]엠에스산업.pdf
       └ 261020\                                ← 생성한 날짜 (YYMMDD)
          ├ [품의서]엠에스산업_261020.hwp
          ├ [품의서]엠에스산업_261020(2).hwp    ← 같은 날 다시 만든 경우
          └ [견적서]엠에스산업_261020.pdf
```

- 붙임 파일은 `[종류]이름` 형식으로 이름을 바꿔 복사하고, 원본은 그대로 둡니다. 붙임 목록에서 `원본 → 복사될 이름`을 미리 볼 수 있습니다.
- 사업자등록증과 통장사본은 기업 폴더 바로 아래에 저장합니다. 같은 내용의 파일이 이미 있으면 다시 복사하지 않고, 내용이 다르면 `(2)`를 붙입니다.
- 나머지 서류와 품의서는 날짜 폴더에 저장합니다. 같은 이름이 있으면 `(2)`, `(3)`…을 붙이고, 덮어쓰지 않습니다.

## exe로 만들 때 (PyInstaller 기준, 아직 만들지 않음)

나중에 Python 없이 실행되는 exe로 묶을 때 확인할 내용입니다. 1·2번은 빌드 전에 코드를 고쳐야 합니다.

### 빌드 전에 코드를 고쳐야 하는 것

1. **설정·저장 폴더 위치**: `hidoc/settings.py`의 `ROOT_DIR`은 "코드 파일이 있는 폴더의 위"를 기준으로 `settings.json`과 기본 저장 위치(`hidoc_output/`)를 찾습니다. 한 파일 exe는 실행할 때마다 코드를 임시 폴더(`sys._MEIPASS`)에 풀었다가 지우므로, 그대로 두면 저장 경로·읽기 방식·Claude API 키 설정이 매번 사라지고 기본 저장 폴더도 임시 폴더가 됩니다. exe로 실행 중일 때(`sys.frozen`)는 exe가 있는 폴더(`Path(sys.executable).parent`)나 사용자 폴더(`%APPDATA%`)를 쓰도록 바꿔야 합니다. `hidoc/html_doc.py`의 `PREVIEW_PATH`(하이웍스 미리보기)도 `DEFAULT_SAVE_DIR`을 쓰므로 같이 해결됩니다.
2. **한글 자동화 캐시**: `hidoc/hwp_doc.py`의 `win32.gencache.EnsureDispatch("HWPFrame.HwpObject")`는 pywin32가 캐시 파일(`gen_py`)을 만들어 쓰는 방식인데, exe 안에서는 캐시를 만들지 못해 오류가 나는 경우가 많습니다. 캐시를 쓰지 않는 `win32com.client.Dispatch`로 바꾸거나 캐시 위치를 쓰기 가능한 폴더로 지정해야 합니다(바꾼 뒤 한글 생성 전체를 다시 시험).

### 빌드할 때 챙길 것

3. **Python 3.14 이상(Tk 9)으로 빌드**: exe에는 빌드한 Python과 Tk가 그대로 들어갑니다. Tk 9여야 입력칸 예시 글자가 기본 `placeholder` 기능으로 나옵니다(아니면 직접 그리는 방식으로 대신함). 빌드 시점의 PyInstaller가 그 Python 버전을 지원하는지도 확인합니다.
4. **자동으로 안 따라오는 패키지**: Windows OCR(`winrt-*` 패키지들), PDF 그림 변환(`pypdfium2`의 pdfium DLL), `pywin32`는 빌드 도구가 빠뜨리기 쉽습니다. 빠지면 프로그램은 뜨는데 일부 기능(예: 스캔본 견적서 읽기)만 고장 납니다. 필요하면 hidden import·collect 옵션으로 넣고, 빌드 후 아래 점검표로 모든 기능을 눌러 봅니다.
   - 첫 화면(문서 만들기·설정 탭), 설정 탭 환경 점검이 모두 정상으로 나오는지
   - 품의서 화면 열기·처음으로, 예시 글자 표시
   - 한글 생성(붙임 복사 포함), 하이웍스용 복사
   - 견적서 불러오기: 로컬(글자 PDF, 스캔 PDF, 이미지), Claude Code(구독), Claude API
   - 설정 유지(저장 경로·읽기 방식을 바꾸고 껐다 켜기)
5. **한 파일 exe와 폴더 묶음**: 한 파일(`--onefile`)은 실행할 때마다 압축을 풀어서 느리고(수 초), 백신이 악성으로 잘못 판단하는 경우가 더 많습니다. 폴더 묶음(`--onedir`)은 빠르고 안정적이지만 파일이 여러 개입니다. 사내 배포는 폴더 묶음을 zip으로 전달하는 쪽을 권장합니다.
6. **크기**: PDF·OCR·이미지·Claude 패키지 때문에 100~200MB 정도로 예상합니다(어림값, 빌드 후 확인).
7. **오류 기록**: exe는 검은 창 없이(`--windowed`) 실행되므로 예상 못 한 오류가 나도 흔적이 남지 않습니다. 오류를 파일(예: exe 옆 `log.txt`)로 남기는 기능을 넣어 두면 동료 PC 문제를 해결하기 쉽습니다.

### 배포·운영

8. **Windows 경고**: 서명하지 않은 exe는 처음 실행할 때 "Windows의 PC 보호" 경고가 뜹니다(`추가 정보` → `실행`). 경고를 없애려면 코드 서명 인증서가 필요합니다(유료).
9. **업데이트**: 코드를 고칠 때마다 다시 빌드해서 다시 나눠 줘야 합니다. 창 제목에 버전 번호를 표시해 두면 누가 예전 버전을 쓰는지 알 수 있습니다.
10. **exe에 넣을 수 없는 것**: 한컴오피스 한글, Windows 한국어 OCR, Claude Code(구독 방식)는 지금처럼 각 PC에 있어야 합니다. exe를 쓰면 `실행.bat`과 `hidoc/check_python.py`의 Python 확인·패키지 설치는 필요 없어지지만, 한글 설치 여부 안내는 프로그램 안으로 옮겨야 합니다.
11. **깨끗한 PC에서 시험**: Python이 없는 PC에서 한 번 실행해 봐야 빠진 파일이 드러납니다.

## 작업 기록

1. 구매 품의서를 엑셀로 만드는 입력창 프로그램을 처음 만듦 (결재란이 있는 표 형식)
2. 실제 사용하는 품의서 양식(제목, 본문, 아래, 번호 항목, 견적내역 표, 지급방식, 붙임)에 맞춰 다시 구성
3. 붙임: 드롭다운으로 종류 선택, 이름은 직접 입력, `[종류]이름` 표기, 입력칸 넓힘
4. 세액: 전체 체크박스 → 별도/포함/없음 3가지 → 품목별 선택으로 변경
5. 저장: 저장 경로 지정, 기업명 폴더 생성, 붙임 파일 복사 및 이름 변경
6. 파일 이름: `[품의서]기업명_YYMMDD`, 같은 이름이면 `(2)`. 붙임에도 날짜와 번호 적용
7. 사업자등록증·통장사본은 기업 폴더에, 나머지는 날짜 폴더에 저장
8. 파일 연결 방식 개선(선택 후 `파일…` 또는 더블클릭), 복사될 이름 미리보기, `비우기` 버튼
9. 견적처·견적 금액 문구 정리 (`1. 견적처 :`, `2. 견적 금액 : 금…원(금…원)`)
