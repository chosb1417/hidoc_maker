# hidoc maker

입력창에 구매 내용을 적으면 한글(`.hwp`) 품의서를 만들고, 붙임 서류를 기업별·날짜별 폴더에 정리해 주는 프로그램입니다.

## 실행

- `실행.bat`을 더블클릭합니다. 필요한 것이 없으면 먼저 설치한 뒤 입력창이 뜹니다.
- 또는 이 폴더에서 `python -m hidoc`을 실행합니다.

### 필요한 것

| 항목 | 설치 |
|---|---|
| Python 3 (3.14에서 확인) | 없으면 `실행.bat`이 winget으로 자동 설치 |
| 파이썬 패키지 (`pywin32`, 견적서 읽기용 `pdfplumber`·`winrt`·`anthropic` 등) | 없으면 `실행.bat`이 `requirements.txt`로 자동 설치 |
| 한컴오피스 한글 (2024에서 확인) | 직접 설치. 없으면 안내만 하고 실행되며, 하이웍스 복사만 쓸 수 있음 |
| Windows 한국어 OCR | 한국어 Windows에는 기본으로 있음. 스캔본 견적서를 로컬 방식으로 읽을 때 필요 |
| Claude API 키 | Claude API 방식으로 견적서를 읽을 때만 필요. 입력창의 `API 키…`로 넣음 |

## 파일 구성

```

├─ dev_run.py          개발용. hidoc 폴더의 .py를 저장하면 입력창을 자동으로 다시 실행
├─ requirements.txt    필요한 파이썬 패키지 목록
├─ hidoc/              프로그램 코드
│  ├─ __main__.py      python -m hidoc 으로 실행할 때 시작점
│  ├─ app.py           입력창(tkinter)
│  ├─ money.py         공급가액·세액 계산, 한글 금액, 을/를
│  ├─ storage.py       저장 폴더 구조, 파일 이름, 붙임 파일 복사
│  ├─ settings.py      폴더 위치, settings.json 읽기/쓰기
│  ├─ hwp_doc.py       한글 자동화로 품의서 .hwp 작성
│  ├─ html_doc.py      하이웍스용 HTML을 클립보드에 복사, output/preview.html에도 저장
│  └─ quote_reader.py  견적서(PDF·이미지)에서 견적처와 품목 읽기 (로컬 / Claude API)
├─ tests/              시험 코드 (python -m unittest)
├─ docs/
│  └─ 문의사항.md      담당자에게 확인할 품의서 작성 기준 (부가세 처리, 할인 표기 등)
├─ output/             기본 저장 경로 (git 제외)

└─ settings.json       이 PC 설정: 저장 경로, 견적서 읽기 방식, Claude API 키 (자동 생성, git 제외)
```

## 사용 방법

1. **기본 정보**를 입력합니다.
   - 구매대상: 본문 문장과 제목에 쓰입니다.
   - 제목: 비워두면 "구매대상 + 구매의 건"으로 자동 작성됩니다.
   - 견적처: 기업명입니다. 꼭 입력해야 하고, 저장 폴더와 파일 이름에 쓰입니다.
   - 지급방식: 기본값은 "선금 50% , 잔금 50%"입니다.
2. **견적내역**에 품목, 수량, 단가, 세액 구분, 비고를 넣고 `추가`를 누릅니다.
   - 목록에서 품목을 고르면 입력칸에 불러와져서 `수정`이나 `삭제`를 할 수 있습니다.
3. **지급방식 상세**를 한 줄에 하나씩 적습니다. 앞에 `- `가 자동으로 붙습니다.
4. **붙임**을 정리합니다.
   - 종류는 드롭다운에서 고르고, 목록에 없는 종류는 직접 입력해도 됩니다.
   - 이름을 비우면 기업명이 들어갑니다.
   - 목록에서 항목을 고르고 `파일…`을 누르거나 항목을 더블클릭하면, 실제 파일이 그 항목에 바로 연결됩니다.
   - `비우기`를 누르면 붙임 목록이 전부 지워집니다.
5. **저장 경로**를 정하고 `한글 생성`을 누릅니다. 한 번 만드는 데 7초쯤 걸립니다.

### 견적서 불러오기

기본 정보의 `견적서 불러오기…`를 누르고 견적서 PDF나 이미지를 고르면, 견적처와 견적내역을 읽어 결과를 먼저 보여 줍니다. `예`를 누르면 입력창에 채우고, 고른 파일을 붙임의 견적서에 연결합니다. 이미 입력된 견적내역은 지워지고 새로 채워집니다.

| 읽기 방식 | 방법 | 비용·조건 |
|---|---|---|
| 로컬 (무료, 기본값) | 글자가 들어 있는 PDF는 글자를 그대로 읽고, 스캔본·이미지는 Windows 내장 OCR로 읽은 뒤 "수량 × 단가 = 금액"이 맞는 줄을 품목으로 찾음 | 무료, 인터넷 불필요, 외부 전송 없음. 양식이 특이하거나 스캔이 흐리면 틀리거나 빠질 수 있음 |
| Claude API | Claude(`claude-opus-5-5`)가 문서를 직접 읽음. 구매대상 이름도 제안함 | API 키와 인터넷 필요. 견적서 1장에 수십 원 정도. 견적서 내용이 Anthropic 서버로 전송됨 |

- 읽기 방식은 마지막에 고른 것을 기억합니다.
- 부가세는 세액 칸이 있으면 `별도`로, "공급가액 + 세액 = 수량 × 단가"이면 `포함`으로 봅니다. 둘 다 아니면 문서의 "부가세 포함/별도" 문구를 따르고, 문구도 없으면 `별도`로 넣은 뒤 알려 줍니다.
- 견적서의 합계와 읽은 품목의 합계가 다르면 알려 줍니다. OCR로 읽은 경우는 숫자를 꼭 확인하세요.

### 하이웍스에 붙여넣기

한글 문서에서 복사해 하이웍스에 붙여넣으면 가운데 정렬이 풀립니다. 대신 `하이웍스용 복사`를 누르고 하이웍스 작성 화면에 `Ctrl+V` 하세요. 정렬, 표 테두리, 글꼴을 HTML에 직접 지정해서 복사하므로 모양이 유지됩니다. 복사할 때 같은 내용을 `output/preview.html`에도 저장합니다(미리보기용, 덮어씀).

`새로 작성`을 누르면 입력 내용이 지워지고, 붙임 목록은 기본 다섯 개로 돌아갑니다.

## 개발할 때 실시간으로 보기

- **하이웍스용 HTML**: VS Code에서 `output/preview.html`을 열고 오른쪽 아래 `Go Live`(Live Server)를 누릅니다. 브라우저에 `http://127.0.0.1:5500/output/preview.html`이 뜨고, 입력창에서 `하이웍스용 복사`를 누를 때마다 자동으로 새로고침됩니다. 파일이 없으면 먼저 한 번 복사하세요.
- **입력창**: `python dev_run.py`로 실행하면, `hidoc` 폴더의 `.py` 파일을 저장할 때마다 입력창이 꺼졌다 다시 켜집니다. 끝낼 때는 터미널에서 `Ctrl+C`. 다시 켜지면 입력한 내용은 지워집니다. 추가 설치는 필요 없습니다.

## 세액 구분 (품목별)

단가 1,100,000원, 수량 1개일 때:

| 구분 | 뜻 | 공급가액 | 세액 | 합계 |
|---|---|---|---|---|
| 별도 (기본값) | 단가 + 10% | 1,100,000 | 110,000 | 1,210,000 |
| 포함 | 단가에 부가세가 들어 있음 (쿠팡 등 소비자가) | 1,000,000 | 100,000 | 1,100,000 |
| 없음 | 면세 (도서, 농산물, 간이·면세사업자, 해외 결제 등) | 1,100,000 | 0 | 1,100,000 |

"포함"일 때 공급가액은 `금액 ÷ 1.1`을 원 단위로 반올림한 값이고, 세액은 금액에서 공급가액을 뺀 값입니다.

견적내역 아래의 `견적금액에 'VAT포함' 표기`를 체크하면 `2. 견적 금액` 줄 끝에 ` VAT포함`이 붙습니다. 표 계산과는 상관없이 글자만 붙습니다. 세액을 0으로 두고 "VAT포함"만 적으려면, 품목을 "없음"으로 넣고 체크하세요.

## 저장 구조

```
저장경로\
 └ 엠에스산업\                               ← 견적처(기업명)
    ├ [사업자등록증]엠에스산업.jpg            ← 기업 공통 서류 (날짜 없음)
    ├ [통장사본]엠에스산업.pdf
    └ 261020\                                ← 생성한 날짜 (YYMMDD)
       ├ [품의서]엠에스산업_261020.hwp
       ├ [품의서]엠에스산업_261020(2).hwp    ← 같은 날 다시 만든 경우
       └ [견적서]엠에스산업_261020.pdf
```

- 붙임 파일은 `[종류]이름` 형식으로 이름을 바꿔 복사하고, 원본은 그대로 둡니다. 붙임 목록에서 `원본 → 복사될 이름`을 미리 볼 수 있습니다.
- 사업자등록증과 통장사본은 기업 폴더 바로 아래에 저장합니다. 같은 내용의 파일이 이미 있으면 다시 복사하지 않고, 내용이 다르면 `(2)`를 붙입니다.
- 나머지 서류와 품의서는 날짜 폴더에 저장합니다. 같은 이름이 있으면 `(2)`, `(3)`…을 붙이고, 덮어쓰지 않습니다.

## 품의서 양식

```
                      품 의 서

제    목   [품의서]  {제목}
──────────────────────────────────────────
{구매대상}을(를) 아래와 같이 구매하고자 하오니 재가하여 주시기 바랍니다.

                  -   아      래   -

1. 견 적 처 : {기업명}
2. 견적 금액 : 금{총계}원(금{한글 총계}원)
3. 견적내역                                (단위 : 개, 원)
   ┌──┬────┬──┬──┬────┬──┬──┬──┐
   │NO│품목│수량│단가│공급가액│세액│합계│비고│
   ├──┴────┴──┼──┼────┼──┼──┼──┤
   │    총계        │ …  │  …     │ …  │ …  │    │
   └────────────┴──┴────┴──┴──┴──┘
4. 지급방식 : {지급방식}
- {상세 1}
- {상세 2}

붙    임 :  [사업자등록증]기업명 1부.
            [견적서]기업명 1부. 끝.
```

- 을/를은 구매대상 마지막 글자의 받침에 맞춰 자동으로 고릅니다.
- 견적 금액에는 세액까지 더한 총계가 들어갑니다.
- 총계 행에는 원래 양식처럼 단가 합계도 넣었습니다.

## 알아둘 점

- 한글 문서의 금액은 계산이 끝난 숫자로 들어갑니다. 생성된 파일에서 숫자를 손으로 고치면 합계는 바뀌지 않으니, 금액이 바뀌면 다시 생성하세요.
- 한글은 화면에 뜨지 않고 뒤에서 실행됐다가 생성이 끝나면 닫힙니다.
- 품목이 많아 한 쪽을 넘는 경우는 아직 시험하지 않았습니다.
- 붙임 목록에 보이는 "복사될 이름"에는 `(2)` 같은 번호가 빠져 있습니다. 실제로 저장된 이름은 생성이 끝난 뒤 뜨는 창에 나옵니다.

## 작업 기록

1. 구매 품의서를 엑셀로 만드는 입력창 프로그램을 처음 만듦 (결재란이 있는 표 형식)
2. 실제 사용하는 품의서 양식(제목, 본문, 아래, 번호 항목, 견적내역 표, 지급방식, 붙임)에 맞춰 다시 구성
